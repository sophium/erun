# ERun

**ERun** (Environment Runner) is a multi-tenant platform-as-a-service for development environments. It lets a team run many isolated tenant/environment pairs against shared Kubernetes infrastructure, with a single CLI, desktop app, and MCP integration that work the same way locally and against remote clusters.

This site documents what ERun is and how to use it.

## What you can do with ERun

- Spin up an isolated runtime pod for any project with one command (`erun init` + `erun open`).
- Switch between local development and remote cloud environments without changing your workflow.
- Build, push, and deploy multi-architecture container images with reproducible, fingerprint-cached builds.
- Talk to a remote pod's tooling through MCP for AI-assisted development.
