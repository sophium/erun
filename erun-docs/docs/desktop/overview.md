# Desktop app

The ERun desktop app is **how most people use ERun day-to-day**. It runs on **macOS** and **Windows** and gives you a single control panel for everything: your projects, your environments, the Agents attached to them, and the cloud machines that back them.

For CI/CD pipelines and headless workflows, use the [CLI](/cli/overview) instead.

## In this section

- [Control panel](/desktop/control-panel) — the sidebar: project and environment status, hover details, theme, cloud machine state.
- [Deploying a version](/desktop/deploying-a-version) — the Runtime tab's version and chart pickers, and Upgrade all.
- [Resources and usage](/desktop/resources-and-usage) — an environment's own CPU, memory, and disk readings, and reclaiming resources.
- [Reviews](/desktop/reviews) — the tenant dashboard's Reviews and Registration tabs, the merge queue, and comment threads.
- [Activities and recovery](/desktop/activities-and-recovery) — the operations queue, failed-deploy recovery, and Investigate.
- [Settings and ports](/desktop/settings-and-ports) — runtime sizing, AI tooling, SSH keys, cloud bindings, and public address management.
- [Orchestrators](/desktop/orchestrators) — host-side AI sessions that coordinate work across linked environments.
- [Diagnostics console](/desktop/diagnostics-console) — the trace log and bug-report tooling behind the terminal area.
- [Terminals and editors](/desktop/terminals-and-editors) — persistent sessions, clickable URLs and paths, and attaching an IDE.
- [Working with an Agent](/desktop/working-with-an-agent) — the in-pod Agent, Claude launch controls, Remote Control, and bringing your own client over SSH or MCP.
- [Workspace sync](/desktop/workspace-sync) — mirroring a remote-agent env's worktree to a local folder.
- [Contribute to ERun from any environment](/desktop/contribute-from-any-environment) — patching ERun itself without leaving the env you're working in.

## Install

Install ERun [via Homebrew or Scoop](/getting-started/install). One command installs both the CLI and the desktop app.
